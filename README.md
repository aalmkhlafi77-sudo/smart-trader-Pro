# التاجر الذكي Pro | Smart Trader Pro

منصة لإدارة بيانات التجارة والتسعير وتكاليف الحمولة، مع توجه **Local-first** (العمل محليًا أولًا) ومزامنة سحابية اختيارية.

## نطاق المشروع

- إدارة الجهات والأصناف والأسعار.
- حساب تكاليف الحمولة والتسعير وتقارير القرار.
- حفظ البيانات محليًا باستخدام IndexedDB.
- واجهة React وTypeScript وVite، مع دعم تنظيم الشاشات والترجمة.
- خدمات خلفية Python وواجهات API ضمن `app/backend/`.

> **حالة التنفيذ:** يضم المستودع خطة معمارية وأجزاء تنفيذية. وجود مكون في الوثائق لا يعني أنه مكتمل أو منشور.

## بنية المشروع

- `app/frontend/` — واجهة المستخدم.
- `app/backend/` — خدمات الخادم.
- `.atoms/ARCHITECTURE.md` — وصف المعمارية والقرارات التقنية.
- `.atoms/PROGRESS.md` — سجل التقدم.

## التطوير

راجع ملفات `app/frontend/README.md` وتعليمات كل جزء قبل التشغيل. لا تُدرج أسرار البيئة أو بيانات الإنتاج في المستودع.

## ملاحظة

هذا المستودع مستقل عن `smart-trader`. لا تفترض تطابق حالة التطوير أو إعدادات النشر بينهما.
