# Smart Trader Pro — التاجر الذكي

**منصة متكاملة لإدارة البيانات التجارية، وحساب تكاليف الشحن والاستيراد، ورقابة أسعار البيع والربحية، وإعداد التقارير الداعمة للقرار.**

## عن المشروع

صُمم التاجر الذكي لمساعدة التجار والمستوردين على تنظيم المعلومات التجارية، ومقارنة أسعار الموردين، وتحليل تكلفة وصول البضائع، وضبط أسعار البيع عبر الفروع والمناطق. يجمع بين العمل المحلي داخل المتصفح ومساحة عمل خاصة مرتبطة بخادم وقاعدة MySQL عند تهيئتها.

## الوظائف الرئيسية

| القسم | الوظائف |
| :--- | :--- |
| الجهات التجارية والأصناف | الموردون والجهات، دليل الأصناف، المواصفات والمرفقات وأسعار الموردين المؤرخة. |
| تكاليف الشحن والاستيراد | حساب تكلفة الحمولة متعددة الأصناف، توزيع المصروفات والجمارك، مقارنة المسارات والتسعير. |
| رقابة أسعار البيع | دليل مستقل للأصناف وتكلفتها الحالية، المناطق والفروع بأرقام فريدة، أنواع أسعار البيع والسجل التاريخي. |
| العروض والخصومات | أسعار مؤقتة، خصم نسبة أو مبلغ لكل وحدة، شروط الكمية وتواريخ السريان ومنع التعارضات. |
| مركز التقارير السعرية | الأسعار السارية والتاريخية، الربح التقديري للوحدة وهامش الربح، بحث متقدم، فلاتر مترابطة، فرز وإعادة تعيين وتصدير النتائج. |
| أدوات الحساب | الحاسبة السريعة والمتعددة والمسودات وأدوات الإدخال السريع. |
| المتابعة | المهام والمواعيد والملاحظات والتنبيهات الصوتية وفق إعدادات الجهاز. |
| الاستيراد والتصدير | استيراد Excel مع معاينة المطابقات والأخطاء قبل الحفظ، تصدير القوالب والتقارير، وملفات PDF في الأقسام التي تدعمها. |
| رفيق التاجر | مساعد Gemini اختياري للمالك، يساعد في إعداد دفعات بيانات ومعاينتها واعتماد الحفظ، والاستفادة من نتائج محرك التكلفة. |
| النسخ الاحتياطي | تصدير واستعادة بيانات العمل بصيغة JSON مع ضوابط الدمج والتحقق. |

### إدارة ورقابة أسعار البيع

هذا القسم مستقل عن محرك تكلفة الحمولة وعن دليل أسعار الموردين. لكل صنف تكلفة حالية واحدة قابلة للتحديث، بينما يحتفظ النظام بأسعار البيع المؤرخة لكل فرع ونوع سعر. الربحية المعروضة تقديرية وتُحسب مقارنة بالتكلفة الحالية، ولا تمثل أرباح مبيعات فعلية أو تكلفة تاريخية.

- إدارة السجلات بالحفظ الصريح والتعديل والحذف، مع معاينة أثر الحذف على الارتباطات.
- تعديلات جماعية للأسعار والتكاليف مع المعاينة قبل الاعتماد.
- رقم الفرع وكود الصنف ونوع السعر وتاريخ السريان مفاتيح مطابقة الاستيراد.
- تقارير الأسعار والربحية حسب الصنف والتصنيف والمنطقة والفرع والوحدة ونوع السعر والفترة ونطاق السعر.
- تصدير Excel عربي من اليمين إلى اليسار، يشمل جميع النتائج المطابقة للفلاتر بنفس ترتيبها.

## المعمارية والتخزين

| الطبقة | التقنية |
| :--- | :--- |
| واجهة المستخدم | React، TypeScript، Vite، Tailwind CSS |
| التخزين المحلي | IndexedDB داخل المتصفح |
| الخادم | Node.js وExpress |
| مساحة العمل الخاصة | MySQL عبر mysql2، مع مزامنة نسخ البيانات والتحقق من رقم المراجعة |
| الاختبارات | Vitest وFake IndexedDB وفحوص TypeScript والترجمة والبناء عبر GitHub Actions |

يدعم التطبيق العربية والإنجليزية والتركية، واتجاه الكتابة من اليمين إلى اليسار للعربية، وواجهات متجاوبة.

## التشغيل المحلي

المتطلبات: Node.js 22 وpnpm 10.4.1.

</div>

```bash
git clone https://github.com/aalmkhlafi77-sudo/smart-trader-Pro.git
cd smart-trader-Pro/app/frontend
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

<div dir="rtl" align="right">

لتشغيل بناء الإنتاج محليًا:

</div>

```bash
pnpm build
pnpm start
```

<div dir="rtl" align="right">

يعمل التطبيق افتراضيًا على المنفذ 3000. لا يلزم إعداد MySQL للعمل المحلي؛ أما مساحة العمل الخاصة والمساعد فتتطلبان تهيئة الخادم وفق [دليل التشغيل](app/frontend/README.md) و[مثال متغيرات البيئة](app/frontend/.env.example).

## هيكل المستودع

- `app/frontend/client/` — الواجهات ومحركات الحساب والتسعير والتخزين المحلي.
- `app/frontend/server/` — خادم Express والتخزين الخاص ومساعد التاجر.
- `app/frontend/README.md` — دليل تشغيل التطبيق وتطويره.
- `.github/workflows/` — اختبارات التكامل المستمر والبناء.
- `app/backend/` و`.atoms/` — مكونات ووثائق معمارية سابقة داخل المستودع؛ ليست مسار تشغيل تطبيق Node.js الحالي.

## الخصوصية والبيانات

يجب عدم إيداع كلمات المرور أو مفاتيح API أو النسخ الاحتياطية الحقيقية في GitHub. بيانات الوضع المحلي تبقى داخل المتصفح، بينما تتم مزامنة مساحة العمل الخاصة عند تسجيل الدخول وتهيئة MySQL. المساعد الاختياري يستخدم خدمة Gemini لمعالجة الطلبات عند تفعيله. يُنصح بحفظ النسخ الاحتياطية في مكان آمن قبل عمليات الاستبدال أو الحذف المؤثر على البيانات.
