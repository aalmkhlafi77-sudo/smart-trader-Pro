# Smart Trader Pro — التاجر الذكي

## تعريف المنصة

**Smart Trader Pro — التاجر الذكي** منصة ويب لإدارة أعمال التاجر وبيانات الموردين والأصناف والأسعار، وحساب التكاليف الفعلية، ومتابعة المهام والمواعيد، وإعداد التقارير وأدوات دعم القرار. تجمع المنصة بين سرعة العمل المحلي داخل المتصفح وإمكانية استخدام تخزين خاص مرتبط بقاعدة **MySQL**، مع أدوات للحساب السريع، المسودات، الاستيراد والتصدير، والنسخ الاحتياطي.

يدعم التطبيق وضع العمل المحلي باستخدام **IndexedDB**، ومساحة عمل خاصة اختيارية تعتمد على **Node.js / Express / MySQL** مع تسجيل الدخول ومزامنة البيانات. راجع [التعريف الشامل للمنصة](../../README.md) للاطلاع على جميع الأقسام.

## الوظائف الرئيسية

يساعد التطبيق التاجر على تسجيل الجهات التجارية والأصناف والمواصفات الفنية والأسعار المؤرخة، ثم إنشاء ملف تكلفة شحنة متعدد الأصناف يوزع المصروفات والجمارك ويقترح سعر البيع. كما يوفر تقارير مقارنة المسارات وتفكيك تكلفة الشحنة، والتصدير إلى Excel وPDF، وإدارة المرفقات والمهام، ونسخاً احتياطية محلية قابلة للاستعادة أو الدمج.

تتوفر أيضاً **الحاسبة السريعة** من المسار `/quick-calculator` لحساب تكلفة الوحدة وسعر البيع التقريبي من مدخلات مستقلة، مع حفظ المسودة وتصدير المدخلات والنتائج إلى Excel. لا تنشئ الحاسبة سعراً للبيع ولا تعدّل مستويات أسعار المورد تلقائياً.

## إدارة ورقابة أسعار البيع

المسار `/sales-pricing` يضم إدارة المناطق والفروع والأصناف وتكلفتها الحالية وأنواع الأسعار وسجل البيع المؤرخ والعروض والخصومات والتعديلات الجماعية. القسم مستقل عن تسعير الموردين ومحرك تكلفة الحمولة. مركز التقارير يدعم البحث والفلاتر والفرز والتصدير العربي RTL وفق النتائج المحددة. حذف السجلات يتطلب تأكيدًا ومعاينة الأثر على السجلات المرتبطة.

## المتطلبات

يتطلب المشروع Node.js 22 و**pnpm 10.4.1**. لا يحتاج التشغيل المحلي إلى قاعدة بيانات أو مفاتيح API. تشغيل مساحة العمل الخاصة يتطلب إعداد MySQL ومتغيرات البيئة على الخادم، وفق [مثال الإعداد](.env.example). شغّل الأوامر من مجلد `app/frontend`.

| الأداة | الأمر |
| --- | --- |
| تثبيت الاعتمادات المقفلة | `pnpm install --frozen-lockfile` |
| تشغيل التطوير | `pnpm dev` |
| اختبار الوحدات | `pnpm test` |
| فحص TypeScript | `pnpm run check` |
| فحص الترجمة | `pnpm i18n-check` |
| بناء الإنتاج | `pnpm run build` |
| تشغيل خادم الإنتاج | `pnpm start` |
| تدقيق جميع التبعيات | `pnpm audit` |
| تدقيق تبعيات الإنتاج فقط | `pnpm audit --prod` |

بعد تنفيذ `pnpm start`، يفتح التطبيق افتراضياً على `http://localhost:3000`. يمكن تغيير المنفذ اختيارياً عند التشغيل، مثل `PORT=3010 pnpm start`.

## النسخ الاحتياطي واستعادة البيانات

بيانات الوضع المحلي محفوظة داخل المتصفح، ومساحة العمل الخاصة تستخدم المزامنة مع MySQL؛ لذلك ينبغي إنشاء نسخة احتياطية بانتظام من صفحة **النسخ الاحتياطي**. يُنشئ التطبيق ملف JSON داخلياً يحتوي سجلات العمل والمرفقات والمهام والإعدادات المرتبطة بالبيانات. لا تشارك ملف النسخة الاحتياطية مع العملاء لأنه قد يتضمن تكاليف وملاحظات خاصة.

عند الاستعادة، اعرض معاينة محتوى الملف أولاً ثم اختر بين الاستبدال الكامل أو الدمج الآمن. رمز الدخول المحلي لا يدخل في النسخة الاحتياطية عمداً، لحماية الوصول إلى الجهاز.

## استيراد Excel

من **الإعدادات ← البيانات** يمكن تنزيل قالب الاستيراد أو رفع ملف Excel لمعاينته قبل الحفظ. القالب يستخدم أوراقاً منفصلة للجهات، الأصناف، أسعار الموردين، المواصفات، والمصاريف. أسعار الموردين تُحفظ في مستويات المورد وسجل التاريخ فقط، بينما المصاريف لا تُقبل إلا مع مرجع حمولة موجود. أي خطأ في المعاينة يمنع الكتابة بالكامل، ويمكن اختيار تحديث المطابق أو تخطيه أو إضافة سجل جديد.

## الاستيراد والتصدير في قسم أسعار البيع

يوفر القسم قالب Excel مستقلًا للمناطق والفروع والأصناف والتكاليف وأنواع الأسعار وأسعار البيع. تتم المطابقة قبل الحفظ باستخدام رقم الفرع وكود الصنف وكود نوع السعر وتاريخ السريان. تبقى الأصفار البادئة في المعرفات، وتُعرض الإضافات والتحديثات والتعارضات قبل الاعتماد. تقارير Excel تتضمن النتائج المفلترة والمرتبة وورقة معايير التقرير.

## الخصوصية والأمان

الأصول والخطوط مضمنة محلياً داخل المشروع. الوضع المحلي لا يتطلب حسابًا على الخادم؛ التخزين الخاص والمساعد الاختياري يتطلبان تهيئة الخادم، ويستخدم المساعد خدمة Gemini عند تفعيله. لا تضع أسرار الخادم أو ملفات بيانات الإنتاج في المستودع. راجع `SECURITY_AUDIT_REPORT.md` للحصول على سجل التنظيف والتدقيق وبنود الاستبعاد من حزمة GitHub.

## الترخيص

يُراجع الترخيص وطريقة الاستخدام التجاري قبل النشر العام أو إعادة التوزيع.

## رفيق التاجر

لتفعيل المساعد في نسخة الخادم، اضبط `GEMINI_API_KEY` في بيئة Node.js وأعد تشغيل التطبيق. يختار `TRADER_ASSISTANT_MODEL` نموذجًا آخر من Gemini عند الحاجة، والإعداد الافتراضي `gemini-3.5-flash-lite`. يستخدم المساعد تسجيل دخول المالك الخاص وتخزين MySQL الحالي. يظهر الطائر بعد التحقق من الجلسة وتفعيل المفتاح. يعرض عند تعذّر العرض ثلاثي الأبعاد صورة الطائر.

يمكن للمالك طلب إنشاء جهة أو أصناف وأسعار شراء مؤرخة، وتعديل الدفعة، ثم معاينة الإضافات والمطابقات واعتماد الحفظ. تُحفظ الدفعة كوحدة واحدة مع التحقق من مراجعة مساحة العمل. تعرض لوحة الشحنات نتائج محرك التكلفة الحالي، ويُرسل إلى Gemini نص المحادثة لفهم الطلب.

يتحقق خادم التطبيق من بصمة نموذج الطائر قبل عرضه. مصدر النموذج هو معرض الواجهات السينمائية، من تصميم Gishere على [Sketchfab](https://sketchfab.com/3d-models/88ed1d3228c14c01ab5078c960d01228).

لاختبار الصلاحيات ومعاينة الدفعة وحفظها محليًا باستجابة محاكاة من Gemini:

```sh
node --import tsx --test server/traderAssistant.test.ts
```
